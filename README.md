# Garden-Advisor-WECAN-academy

Our team name ~ The Hopeless and The Damned

## Who is it for?
AI chatbot is for smallholder farmers, we came up with this because Many farmers traditionally rely on advice from agrovets and other fellow farmers which, while well-intentioned, is not always based on expert and up-to-date agronomic information.

## solution it provides
This chatbot basically provides real-time guidance on soil health, weather, pest control & crop management depending on the county ones is coming from and plants they intent to use and problems they experience during their farming season. This gives farmers a reliable place to ask questions, share images of their crops & receive guidance drawn from a structured library of expert agricultural knowledge on soil advice, crop recommendations, planting guidance.

## Setup
1. Clone: git clone 
2. Create .env file with GOOGLE_API_KEY
3. Install: pip install -r requirements.txt
4. Run: "Garden Advisor.py"
